# defense-report

Цель — честный отчёт, который выдерживает вопросы наставников. Ни одной цифры не из
`results/metrics_history.csv`.

## Источники

- `results/metrics_history.csv` — все метрики (последняя строка по каждому `task, dataset, method`
  + baseline для «было/стало»). Если нужных строк нет — сначала скилл `evaluate-model`.
- `CLAUDE.md` — цели, позиционирование, валидация. `/mnt/project-files/repo/PLAN.md` — этапы.
- Код `anemia/`, `scripts/` — для описания метода (ссылки `файл:строка`).

## Структура (`reports/defense_<YYYY-MM-DD>.md`)

1. **Задача и позиционирование** (3–4 строки): скрининг риска, не диагноз; офлайн (Edge AI);
   выход — риск низкий/средний/высокий, диапазон Hb, «по какой ткани и почему», PDF для врача.
2. **Данные**: таблица набор / n пациентов / население / разметка / лицензия. Почему взрослые,
   дети и телефон отчитываются раздельно.
3. **Метод**: конвейер фото → глаз → сегментация → нормализация цвета → модель → QC.
   Формулы цвета (sRGB→линейный, Lab, HSI, EI, HHR) по одной строке; что обучено, что эвристика.
4. **Валидация**: StratifiedGroupKFold по пациенту, 5 фолдов, seed 0; порог и калибровка —
   вложенная CV на train; поиск копий (dHash + миниатюры); стресс-тест света 2700–7500 K.
5. **Результаты**: таблица из CSV (метрика, значение, 95% ДИ, n, цель, ✓/✗) + «было/стало»
   к baseline v10/v11. Bland–Altman: bias и пределы согласия.
6. **Что не достигнуто и почему**: каждая непройденная цель — цифра, разрыв, 1–2 гипотезы,
   что делаем.
7. **Ограничения**: размер выборки, фото с насадки ≠ смартфон, нет наших фото с лабораторным Hb,
   CP-AnemiC без возраста (нормы <5 лет), склера без экспертной разметки.
8. **Вопросы наставников** — 8–10 пар «вопрос → короткий ответ с цифрой». Обязательно:
   утечка между train/test; почему AUC, а не accuracy; что при плохом свете; чем лучше
   визуального осмотра; что будет при ложноотрицательном; почему не диагноз; как работает офлайн;
   отличие от v10 (синтетика, подгонка порогов под 3–4 фото).
9. **Следующие шаги** и что нужно от команды (фото, разметка, доступы).

## Правила

- По-русски, кратко, цифрами; без маркетинговых слов («высокая точность», «революционный»).
- Каждая цифра — с ДИ и `n`; метрики на синтетике не упоминать как результат.
- Цель не достигнута — так и писать.
- Без медицинских данных (снимков, Hb отдельных пациентов): репозиторий публичный.
- По запросу — та же структура слайдами (1 раздел = 1 слайд).
