# defense-report

Цифры — только из `results/metrics_history.csv` (каждая с 95% ДИ и `n`). Нужных строк нет →
сначала `/evaluate-model`.

## Что собрать

1. **Метрики**: таблица по наборам (взрослые Eyes-defy / дети CP-AnemiC / наши фото):
   IoU конъюнктивы, MAE Hb г/л + Bland–Altman, AUC, чувствительность/специфичность при пороге,
   «свет ±г/л»; столбцы «цель» и ✓/✗; «было/стало» к baseline v10/v11.
2. **Примеры сегментации**: 4–6 снимков невиданных пациентов (хорошие и провалы) — фото,
   маска врача, наша маска, IoU. Картинки сохранять в `<data>/results/defense/` (медицинские
   данные: не в git, в отчёте — путь).
3. **Ограничения**: размер выборок, фото с насадки ≠ смартфон, мало своих фото с лабораторным Hb,
   CP-AnemiC без возраста, склера без экспертной разметки; что не достигнуто и почему.
4. **Позиционирование**: скрининг риска, не диагноз; офлайн; что получает пользователь и врач.
5. **Вопросы наставников** (8–10, ответ с цифрой): утечка train/test; почему AUC; плохой свет;
   ложноотрицательный результат; чем отличается от v10 (синтетика, пороги под 3–4 фото).

## Результат

`reports/defense_<YYYY-MM-DD>.md` (без медицинских данных) + таблица для слайдов/дашборда в
проекте «Анемия» на claude.ai. По-русски, кратко, без слов «высокая точность».
