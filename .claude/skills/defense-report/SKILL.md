# defense-report

Цифры — только из `results/metrics_history.csv` (с 95% ДИ и `n`). Нужных строк нет → сначала `/evaluate-model`.

1. **Было/стало**: baseline v10/v11 → последний прогон, по наборам (взрослые / дети / телефон): IoU, MAE Hb,
   AUC, чувствительность/специфичность, «свет ±г/л», столбец «цель» и ✓/✗.
2. **Примеры сегментации**: 4–6 невиданных пациентов (удачи и провалы): фото, маска врача, наша маска, IoU →
   `<data>/results/defense/` (медицинские данные, не в git).
3. **Ограничения**: размер выборок, насадка ≠ смартфон, мало своих фото с лабораторным Hb, CP-AnemiC без возраста,
   склера без экспертной разметки; непройденные цели — с цифрой и гипотезой.
4. **Честная формулировка точности** — одна фраза для слайда, например: «На N взрослых невиданных пациентах
   AUC X [ДИ]; при чувствительности Y специфичность Z. Это скрининг риска, не измерение Hb и не диагноз».
5. **Вопросы наставников** (5–8, ответ с цифрой): утечка, почему AUC, плохой свет, ложноотрицательные, отличие от v10.

Результат — `reports/defense_<YYYY-MM-DD>.md` без медицинских данных. Без слов «высокая точность».
