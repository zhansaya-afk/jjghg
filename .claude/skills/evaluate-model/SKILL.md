# evaluate-model

Цифры точности берутся только из `scripts/evaluate.py`. Ничего не считать «на глаз» и не пересказывать.

## Шаги

1. **Тесты.** `pytest -q`. Красные тесты → сначала чинить, оценку не запускать.
2. **Данные.** Проверить, что есть `<data>/manifest.csv` (`--data` или `ANEMIA_DATA`). В облаке Claude
   доступен только CP-AnemiC (раскладывается из `md/history/097_*/*.zip` вне репозитория).
   Eyes-defy и `data/phone/` — только в Colab: тогда не запускать, а написать команде,
   какие ячейки `notebooks/colab_train.ipynb` запустить и в каком порядке, и ждать вывод.
3. **Смоук.** `python scripts/evaluate.py --data <dir> --dataset cp_anemic --model ridge --no-history --tag smoke`
   — код работает, строки не пишутся в историю.
4. **Прогон.** `python scripts/evaluate.py --data <dir> --tag <этап>_<что_менялось>`
   (тег латиницей, напр. `s2_unet_mnv3`). Лог уходит в `results/logs/`, в разговор — только итог.
5. **Было/стало.** Из `results/metrics_history.csv` взять последнюю строку с тем же
   `task, dataset, method` (или baseline) и построить таблицу:

   | Набор | Метод | Метрика | Было (тег) | Стало (тег) | Δ | Цель |
   |---|---|---|---|---|---|---|

   Метрики: IoU/Dice (seg); MAE г/л [95% ДИ], bias и LoA Bland–Altman, AUC [ДИ],
   чувствительность/специфичность [ДИ] при пороге из train-фолдов, `sens_hb100`,
   «свет ±г/л» (`light_med`, `light_p90`). Взрослые / дети / телефон — отдельными строками.
6. **Вердикт** по целям из CLAUDE.md (IoU ≥ 0,75; AUC ≥ 0,85; sens ≥ 0,80 при spec ≥ 0,70;
   свет ≤ ±5 г/л): достигнута / нет, на сколько. Перекрытие ДИ «было» и «стало» → писать
   «разница в пределах шума».
7. **Ухудшение** любой ключевой метрики вне ДИ → дальше по плану не идти; гипотезы причин
   и что проверить.
8. Коммит: код + `results/metrics_history.csv`. OOF-предсказания (`<data>/results/`) и `data/`,
   `models/` не коммитить.

## Запрещено

- Метрики на синтетике выдавать за точность (синтетика — только «код запускается»).
- Подбирать порог, калибровку, признаки или гиперпараметры на тестовых фолдах.
- Менять фолды манифеста ради сравнения: все модели — на одних фолдах.
- Удалять или править старые строки `metrics_history.csv`.
- Писать цифры без ДИ и без размера выборки `n`.
