# run-experiment

1. **Гипотеза** одной фразой: что меняем и какую метрику ожидаем улучшить. Одно изменение за раз.
2. **До/после на одних фолдах**: базовая и новая версия, `scripts/evaluate.py` с тегами `exp<N>_base` / `exp<N>_new`.
3. **3–5 повторов** с разными seed (seed модели и вложенной CV; фолды пациентов из манифеста не менять) → среднее ± разброс (SD, min–max).
4. **Решение**: принять, только если улучшение больше разброса между повторами и вне 95% ДИ не хуже по остальным
   ключевым метрикам. Иначе — отклонить (или «не доказано»).
5. Гиперпараметры, пороги, калибровка, отбор признаков — только внутри обучающих фолдов. Тестовые фолды не видят ничего.
6. **Запись** строкой в `results/experiments.csv` (коммитится; только агрегированные метрики, без данных пациентов):
   `date, id, hypothesis, change, dataset, metric, before, after, spread, n_seeds, decision, commit`.
7. Ответ — таблица ≤ 10 строк и решение. Отклонённые эксперименты тоже записывать.
