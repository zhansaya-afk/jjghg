Эффект: +1 пациент, 1 исправленная маска; после правки нужен переобучение Я1.
2. **ED_India_2: исключить все 3 маски из IoU и обучения сегментации.** Внутри маски — прямоугольный кусок другого кадра: |маска − фото| = 73 из 255 при медиане 1,0 у остальных. В `error_analysis` уже исключается; в `evaluate`/`train_core` — нет.
3. **Беременность:** в `main` `anemia/data.py` пишет `pregnant=False`; в рабочей ветке (fc8d361) уже `None`. В отчёте для защиты — оговорка: 86 женщин без статуса беременности.

5. **Косметика:** маски читать только через `cv2` (`anemia.io.load_mask` так и делает; Pillow на 187 файлах падает); в India/8 брать маску без `(1)` (копии побайтно равны — на цифры не влияет).

Без исправлений: выбросы Hb, дубли, размеры и положение масок (кроме ED_India_2) — проблем не найдено.

## Ручная проверка (примеры глазами)

- **Пары с одинаковыми (страна, пол, возраст, Hb):** 3 пары (2 из Индии, 1 из Италии; id — в `<data>/results/data_audit/`, вне git). На фото разные глаза (форма века, сосуды, радужка). Такое число совпадений ожидаемо случайно (~3 пары на 95 человек при шаге Hb 0,1 г/дл). Исключить левый и правый глаз одного человека нельзя. Предложение: склеить каждую пару в один `group` манифеста — фолды строже, данных не теряем.
- **ED_India_2:** маска — прямоугольник с куском другого кадра, а не контур ткани (подтверждено визуально).
- **CP, 5 ближайших пар (MAD 0,020–0,030):** разная форма выреза, не копии. dHash на гладких вырезах бесполезен (9 317 пар с dHash ≤ 10) — правило манифеста «dHash ≤ 3 **и** MAD < 1%» подтверждено.
