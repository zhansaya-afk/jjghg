# Baseline проекта HemaVision

**Текущий baseline — `main`, коммит `0d4e2dbfc842bf556ac134c3d153f496888c9157` (`0d4e2db`, PR #40, 2026-11-20).**
Любой кандидат сравнивается с ним на тех же пациентах и фолдах. Кандидаты и их статус — [README.md](README.md).

## Почему цифры измерены на `970ef2e`
Метрики получены `evaluate.py --task core` на `970ef2e` (запуск `20261120-160257-core_970ef2e-a13873`).
Между `970ef2e` и `0d4e2db` модель, признаки и пороги не менялись: штамп совместимости модели
(`anemia/model_store.compat_stamp`, sha1 модулей FEATURE_MODULES + FEATURE_REV) одинаков — `1ac0474dcb82`
у обоих коммитов. PR #40 исправил разбор Hb/пола/беременности из анкеты, проверку sha256 модели лица и карточку
качества в UI — это не входит в путь `evaluate.py` на Eyes-defy. Повтор: A0 эксперимента 2026-11-21 дал те же цифры.
